## Layout

| Path | Contents |
| --- | --- |
| `ethereum/` | `NoriSnapshot.sol`, `queries.ts` (query ids, mainnet queries), `snapshotProof.ts` (TS mirror of the checks), tasks, tests |
| `ethereum/types/` | Generated by `hardhat compile`. Never hand-edit |
| `ethereum/vectors/` | Builds `test-vectors/nori-snapshot/` (`npm run vectors`), including the 2030 Kelp replay |
| `nori-read/` | Rust: `verify_snapshot_result` and account loaders |
| `programs/nori-read-example/` | Smallest consumer + surfpool test. Its keypair is committed and test-only |
| `programs/backstop/` | Guards: proven backing vs Solana supply ([diagram](docs/backstop-guard.drawio.png)) |
| `client/` | Sample TS client and keeper CLI (`npm run keeper`). Encoders are pinned to Rust bytes. `fake-prover` is for local dry runs only. Tests run with `node --test` on the build, since the wasm hasher breaks jest |
| `test-harness/` | Surfpool helpers for program tests (deploy, plant accounts, time travel) |
| `sdk/`, `bridge-head/` | Submodules. Their npm packages are root workspaces; their crates are path deps |

## Commands

```bash
npm install && npm run build
npm test                          # ethereum (incl. vector drift check) + client
npm run test:fork -w ethereum     # mainnet fork (network)
npm run vectors -w ethereum       # regenerate test vectors

cargo test -p nori-read
export CFLAGS="-isystem $HOME/.cache/solana/v1.54/platform-tools/llvm/sbpf/include"
cargo build-sbf --manifest-path programs/<name>/Cargo.toml
cargo test -p <program>           # surfpool tests
cargo clippy --workspace --all-targets && cargo fmt --all --check
```

## Quirks

- `sdk/node_modules` is a symlink to the root's (made by `postinstall`). Don't `npm install` inside `sdk/`.
- Build the sdk packages before `ethereum` tests; they deploy the queue from the sdk's artifact.
- Node 23 needs `--experimental-wasm-modules` for `nori-hash-utils`; the test scripts set it.
- `Cargo.lock` was seeded from `sdk/Cargo.lock` for its SBF pins. Don't `cargo update` alloy.
- surfpool must be 1.5 or later (1.0 breaks `solana program deploy`).
- A Hardhat fork's clock lags real time. Align it (`evm_setNextBlockTimestamp`) before testing guards, or no supply checkpoint falls in the window.
- Config: one root `.env` (`.env.example`) for Hardhat, the ethereum scripts and the keeper; deploy outputs land in `ethereum/.env.nori-eth-*`. The shell environment wins over both; `dry-run.sh` blanks the queue settings so it never uses yours.
- Dry run of the whole loop without a prover: `scripts/dry-run.sh [--eth-rpc URL] [--solana-rpc URL] [--yes]`. It uses ports 18545/18899 and a temp dir. Deploy outputs go to `NORI_ETH_ENV_DIR` when set.

## Rules that bite

- `NoriSnapshot` storage: `commitments` at slot 0, `snapshotCount` at slot 1.
- Result leaf = `sha256(0x00 ++ queryId ++ result)`. Never drop the `0x00`: without it a forged result can pose as a tree node (regression test in the vectors).
- Snapshot indices start at 1, and time keys are never zero. The reader rejects zero keys.
- The committed word is `root | 1<<255`. Readers reject words without the top bit.
- Solidity, `snapshotProof.ts` and `nori-read` must hash identically; the tests pin them together.
